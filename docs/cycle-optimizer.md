# Работа с длинной задачей

Скилл `$cycle-optimizer` сохраняет ход задачи, чтобы её можно было продолжить
в другом чате. Запускай его, когда этапов много или нужно проверить изменение
общих правил работы. В Codex выбери skill в меню `/` либо укажи его имя в сообщении.

В досье задачи хранятся условия приёмки (`contract.md`), текущее состояние
(`current.md`), журнал и итоговый разбор (`review.md`). На значимых этапах агент
создаёт отдельные checkpoints; прежние снимки сохраняются.

## Продолжить задачу

Из `w-tooling`:

```sh
npm run task:cycle -- task resume ACME-17 --repo search-worker
npm run task:cycle -- --help
```

Замени код и репозиторий своими. Досье принадлежит задаче и хранится в её
репозитории, в `.project/task-runs/`. В журнале нужны фактический результат,
отличие от ожидаемого, следующий шаг и порядок восстановления при ошибке.
Секреты и сырые сессии Codex в досье не записываются.

[Команды досье](../templates/workspace-skills/cycle-optimizer/references/task-dossier.md)

## Проверить новую версию правил

Изменение rules, skills или agents оформляется отдельным кандидатом с точными
файлами, базовым коммитом и критериями проверки. Следующие задачи проверяют этот
кандидат и сохраняют результаты у себя. Человек принимает решение после технических
проверок; новые результаты требуют повторного решения. Общие правила автоматически
не меняются. После `fail` или `rejected` нужен новый кандидат.

```sh
npm run task:cycle -- experiment list --class tooling --facet agent-workflow
```

Кандидаты, результаты и checkpoints сохраняются новыми записями. Текущее досье
можно обновлять; прежние доказательства остаются доступны.
