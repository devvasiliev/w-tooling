# Проверка после рефакторинга

Скилл `$echo-remover` ищет остатки прежнего решения после переноса,
переименования или замены кода. В Codex укажи его имя в сообщении:

```text
$echo-remover Проверь ACME-17 в search-worker после переноса обработки событий.
Прежний путь: legacy-events. Текущий владелец: event_handler.py.
```

Агент проверит вызовы, конфигурацию и тесты. Результат будет одним из следующих:

- `clean`: лишних остатков не найдено;
- `cleanup-required`: есть подтверждённые остатки и план исправления;
- `blocked`: требуется уточнить, какое поведение должно работать сейчас.

Echo Remover читает файлы. Основной агент применяет подтверждённые правки,
затем отдельный валидатор проверяет результат. Строка `PROFILE_BINDING` показывает,
был ли доступен именованный профиль; при его отсутствии аудит выполняет основной агент.

Рабочий rollback, действующие адаптеры совместимости и незавершённые миграции
сохраняются. То же относится к обязательным архивам аудита и текущим терминам
продукта. Если код ещё используется или его владелец неизвестен, удаление ждёт
решения владельца. Для временного решения укажи условие его удаления.

Обновить skill в репозиториях: `npm run agents:sync`.
Проверить копии: `npm run agents:check`.
