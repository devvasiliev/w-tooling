# Добавить общий skill и агент

Из `w-tooling` выполни:

```sh
npm run create-workspace-harness -- \
  --name owner-auditor \
  --display-name "Owner Auditor" \
  --description "Проверяет владельца поведения и границы изменений" \
  --dry-run
```

Команда покажет будущие файлы. Проверь список и повтори запуск с теми же
параметрами, убрав `--dry-run`. Имя задаётся в kebab-case; существующее определение
не перезаписывается.

Генератор создаёт `SKILL.md`, настройки отображения, read-only профиль агента
и сценарии проверки. Затем копирует инструкции в зарегистрированные репозитории.
Это подходит для общего процесса команды; правило одного сервиса храни в самом сервисе.

Заполни предметные шаги в `SKILL.md` и сценарии в `evals/matrix.json`.
Сохрани строки `PROFILE_BINDING`: по ним видно, какой агент выполнил проверку.
После правок запусти:

```sh
npm run agents:sync
npm run agents:check
npm test
```

При ошибке выполни действие из поля `Следующий шаг`.
